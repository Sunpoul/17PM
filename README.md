# Павел Маркелов — портфолио

Next.js 15, React 19, TypeScript, Tailwind CSS 4. Статический экспорт.

- `npm install` — зависимости
- `npm run dev` — локальная разработка
- `npm run build` — проверка типов и production-сборка в `out/`

Раздел проектов содержит четыре работы из профиля https://dribbble.com/sunpoul. Концепции отмечены в подписях; исходные названия, ссылки и URL изображений сохранены в project-sources.json. Компании и должности приведены по исходному брифу. Контакт: sunpoul@gmail.com.

Фотография: Unsplash, https://unsplash.com/photos/1487958449943-2429e8be8625 (источник файла: images.unsplash.com/photo-1487958449943-2429e8be8625). Шрифты: Google Fonts — Cormorant Garamond, Manrope, IBM Plex Mono.

Адаптивная сетка: 12 колонок; контрольные ширины 600 / 900 px. Разделы «Инфо», «Проекты» и «Контакт» переключаются кнопками. Контактная форма составляет mailto-письмо и открывает почтовое приложение; автоматической отправки нет. Доступность: семантическая разметка, ссылка пропуска навигации, видимый клавиатурный фокус, reduced motion. SEO: metadata, Open Graph, sitemap и robots.

Интерактивность: модальные окна через нативный dialog (Escape, удержание фокуса, возврат фокуса). CTA предлагает Email / VK / Telegram; форма сохраняет черновик для Email. Кейсы открываются в галерее с клавиатурой и свайпами. Arte содержит три изображения, остальные кейсы — по одному. Есть переключение кейсов. Раздел «Блог» содержит пустое состояние.
